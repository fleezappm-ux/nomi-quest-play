# NOMI QUEST 試遊版

飲み会を題材にした13種類のカードゲーム。開発版v0.6.33を試遊する配信用リポジトリです。

## 遊び方
名前・アバター・遊び方・ターン数を選んで開始。あなた＋NPC3人、または4人で1台を順番に操作できます。ゲーム内の「あそび方」を参照してください。

全種類を試すときはホームの「テストモード：全13ゲームを選ぶ」を使います。DRINKは仮想カウントで、実際の飲酒は不要です。セーブはなく、再読み込みでリセットされます。

## 開発状況・対応環境
単体HTMLにCSSとJavaScriptを内包し、外部API・画像・音声への依存はありません。PCとスマートフォンで試遊してください。Android実機での最新版の確認と安定認定は未完了です。

## 管理ルール
開発の正本は別の非公開リポジトリで管理します。この配信用HTMLを独立に修正しません。人間が承認した版だけをコピーして更新します。

安定基準版はAndroidで30ターン確認済みのv0.6で、非公開の開発先に変更せず保存しています。今回のv0.6.33は開発版です。1バージョン1主要変更を原則とし、安定認定にはユーザーの実機確認と明示承認が必要です。
