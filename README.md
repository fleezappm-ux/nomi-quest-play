# NOMI QUEST 試遊版

飲み会を題材にした14種類のカードゲーム。開発版v0.6.48を試遊する配信用リポジトリです。

## 遊び方
3〜6人と指定キャラを選んで集合ロビーへ。各キャラのDRINKと所持アイテムを見てゲーム開始。詳細設定からNPC・ターン数・テストを選べます。ゲーム内の「あそび方」を参照してください。

全種類を試すときはホームの「ゲームを選んでテスト」を使います。DRINKは仮想カウントで、実際の飲酒は不要です。セーブはなく、再読み込みでリセットされます。

## 開発状況・対応環境
単体HTMLにCSSとJavaScriptを内包し、外部API・画像・音声への依存はありません。PCとスマートフォンで試遊してください。Android実機での最新版の確認と安定認定は未完了です。

## 管理ルール
開発の正本は別の非公開リポジトリで管理します。この配信用HTMLを独立に修正しません。人間が承認した版だけをコピーして更新します。

安定基準版はAndroidで30ターン確認済みのv0.6で、非公開の開発先に変更せず保存しています。今回のv0.6.48は開発版です。1バージョン1主要変更を原則とし、安定認定にはユーザーの実機確認と明示承認が必要です。

## スマホ1台モード
ホームの「📱 スマホ1台で回して遊ぶ」から人間3〜6人で開始。振動を除く13ゲーム。充電は入力なしでHIGH／LOWだけ抽選、実残量は会場で比較。同率全員対象。充電のDRINK・アイテムは会場で確認し、アプリには反映しません。テストにも遊び方設定が適用されます。

## 参加準備・ロビー
指定6キャラの名前と専用顔アイコン、重複なしプルダウン。ロビーはDRINK大数字・お助けタップ説明。Android実機未確認。
