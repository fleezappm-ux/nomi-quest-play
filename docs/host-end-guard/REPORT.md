# POP 0.42 ホスト終了の誤タップ対策

- 通常の操作列から終了操作を外し、閉じた「ホスト設定」に移動。
- 終了方法画面では「ゲームを続ける」を先頭に配置。
- 終了確認チェックを入れるまで、切捨て終了・最終精算への移行を無効化。
- 戻ると確認チェックを解除し、設定も閉じる。
- 最終精算後の「これでゲームを終了する」に確認ダイアログを追加。
- ゲーム・チケット計算・Firebase設定・ルールは変更なし。v0.6.1添付原本のSHA256も不変。

検証: Chromiumの320/360/390/412pxで、初期折りたたみ、チェック必須、キャンセル時の状態維持、再表示時リセット、最終終了確認のキャンセル/承認を確認。横はみ出し・画像エラー・JS例外なし。通信部分はローカル代替、Android実機・実通信は未確認。
